pyplaypen-sandbox

One-shot subprocess sandbox for running Python inside a container.

Not a hostile-code sandbox. The container around this process is the accepted trust boundary. This library adds defense in depth inside that boundary; it does not hold against code that deliberately tries to escape it. For that, use gVisor, Firecracker, or a VM.

What it enforces

Every call forks a fresh child, in its own process group, that:

  • runs under a wall-clock timeout that kills the whole process group, not just the child, so background descendants can't outlive the call
  • applies POSIX rlimits pre-exec — CPU seconds, memory, process count, max file size
  • drops from root to a dedicated non-root UID (Linux exempts root from RLIMIT_NPROC, so this is what makes it real)
  • reaps orphaned grandchildren after teardown, via PR_SET_CHILD_SUBREAPER on Linux
  • captures stdout/stderr bounded and SHA-256-hashed, and returns the final expression as JSON
  • collects workspace files as artifacts, rejecting symlinks and anything that would escape it
  • logs a structured audit record naming exactly what was enforced vs. best-effort vs. unsupported on the current platform

Install

pip install pyplaypen-sandbox

No dependencies, required or optional.

from pyplaypen_sandbox import run

result = await run("1 + 1", artifact_dir="./artifacts")
# {"status": "ok", "return_value": 2, ...}

The one hook

Nothing about numpy, pandas, httpx, or any other library is built in. If sandboxed code needs to call out to something, or return a type this library doesn't know, you give Sandbox an import path to a plain function — globals_provider for what code can call, type_projector for what it can return. Both run inside the child, bound by the same rlimits as everything else. numpy/pandas support ships as the worked example of that mechanism.

Lower-level pieces

This library's guarantees don't stop at execute(). Sandbox.run_process(argv, cwd=...) is its argv-only twin: same isolation, no JSON protocol, for code that already speaks in files and exit codes. argv accepts any process: a script, a shell command, a compiled binary. And pyplaypen_sandbox.privilege is the two functions underneath both: real rlimits and a real UID drop, usable in a plain subprocess.Popen(preexec_fn=...) without adopting anything else here.
